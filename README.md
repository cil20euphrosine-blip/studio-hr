# Studio HR

PWA de visualisation et pilotage documentaire. Le dépôt ne contient aucune donnée immobilière privée.

## Installation
Activer GitHub Pages sur `main` / `/(root)`, ouvrir l'URL HTTPS, puis importer une sauvegarde JSON privée avec « Restaurer ».

## Confidentialité
Les fiches sont exclusivement stockées dans le navigateur local. Ne jamais committer un export JSON privé. Sauvegarder régulièrement ses données.
